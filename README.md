### 🌸 Featured Projects

#### 🍱 Wolt-Inspired Food Delivery Platform

*Full-stack university team project*

A food-delivery platform inspired by Wolt, designed to support the journey from discovering restaurants to placing orders.

- **User experience:** Restaurant discovery, menus, shopping carts, checkout, and order history.
- **Web & mobile:** React and React Native / Expo interfaces.
- **Backend & data:** Node.js / Express REST API, MongoDB / Mongoose, and authentication with JWT.
- **Recommendation engine:** A C++ TCP-based service using collaborative filtering to recommend products.
- **Testing & deployment:** GoogleTest and Docker Compose.

**Technologies:** `C++` `JavaScript` `React` `React Native` `Expo` `Node.js` `Express` `MongoDB` `Mongoose` `Docker` `GoogleTest`
